# Portfólio — Análise de Dados aplicada à Cobrança

Olá! Sou a Alana, atuo com operações de cobrança/contas a receber, análise de dados e automação de processos em uma SaaS B2B do setor fiscal. Este repositório reúne 3 projetos que desenvolvi para otimizar o dia a dia do setor de cobrança em que trabalho: da automação de relatórios manuais até análises para reduzir a inadimplência.

## Projetos

### 1. [Automação do tratamento de relatórios de cobrança](./projeto-1-automacao-relatorios)
Scripts em Python que automatizam o tratamento diário dos relatórios que embasam o trabalho das analistas de cobrança — um processo manual que passou a ser executado em segundos.

**Destaques:** pandas, tratamento de dados de contato, segmentação de carteira por regras de negócio, distribuição balanceada entre a equipe.

### 2. [Cálculo do caixa (recuperação) da cobrança](./projeto-2-calculo-caixa)
Modelagem de uma regra de negócio não trivial para medir corretamente quanto do caixa recebido é, de fato, resultado da atuação da cobrança — com um comparativo direto de como evoluí o cálculo em relação ao método usado anteriormente pelo setor.

**Destaques:** pandas, biblioteca `holidays`, regras condicionais por dia da semana.

### 3. [Uso da plataforma x inadimplência](./projeto-3-uso-x-inadimplencia)
Análise cruzando dados de uso do produto (SaaS) e de relacionamento com o time de Customer Success para identificar pontos de atenção que antecedem a inadimplência.

**Destaques:** pandas/numpy, cruzamento de múltiplas bases, janelas de tempo móveis, comparação entre grupos.

## Sobre mim

`Python` · `pandas` · `numpy` · `openpyxl` · `matplotlib` / `seaborn` · `holidays`

## Sobre os dados

Nenhum dado real de clientes, colegas ou parceiros comerciais está incluído neste repositório. Todo o código foi adaptado a partir das versões usadas internamente: caminhos de arquivo, nomes de pessoas e de parceiros foram generalizados, e os relatórios de entrada (que contêm dados de clientes) não fazem parte do repositório.
